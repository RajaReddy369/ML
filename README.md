# Machine Learning Fundamentals 🤖

A structured collection of machine learning implementations, experiments,
and practical notebooks covering classical Machine Learning algorithms.

This repository is being developed as part of my preparation for
Machine Learning projects, interviews, and real-world AI applications.

---

## 📌 Objectives

The main objectives of this repository are:

- Understand the mathematics and intuition behind ML algorithms
- Implement and experiment with different ML models
- Compare models using appropriate evaluation metrics
- Understand preprocessing and feature engineering
- Analyze model performance
- Practice ML using real datasets
- Build a strong foundation for Deep Learning, Generative AI and Agentic AI

---

- Logistic Regression
- Naive Bayes

- Decision Trees

- AdaBoost

- Support Vector Machines

- Feature Scaling

### Model Evaluation

- Accuracy

- ROC-AUC
- MAE

- RMSE
- R² Score

## 🌳 Ensemble Learning

Special focus is given to ensemble learning algorithms:

### Random Forest

Concepts studied:

- Bagging
- Bootstrap Sampling
- Decision Tree Ensembles
- Feature Randomness
- Feature Importance
- Hyperparameters
- Advantages and Limitations

### AdaBoost

Concepts studied:

- Weak Learners
- Sequential Learning
- Sample Weighting
- Misclassification Weight
- Ensemble Prediction
- Advantages and Limitations

### Random Forest vs AdaBoost

Experiments are performed to compare:

- Accuracy
- Precision
- Recall
- F1 Score
- Training Time
- Prediction Time
- Model Complexity
- Overfitting Behaviour
